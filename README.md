Manipulação de Vetores em Java
Este projeto em Java apresenta um menu interativo no console que permite ao usuário realizar diversas operações com um vetor de 10 elementos inteiros. O programa inclui funcionalidades como entrada manual, geração de números aleatórios, soma, média, identificação de maior/menor valor, entre outras.

📋 Funcionalidades
O programa oferece as seguintes opções:

Coletar dados do vetor – Entrada manual dos valores.

Randomizar os valores do vetor – Gera números aleatórios com um valor máximo definido pelo usuário.

Imprimir dados do vetor – Mostra os valores armazenados no vetor.

Imprimir vetor invertido – Exibe o vetor de trás para frente.

Somar todos os valores do vetor – Realiza a soma total dos elementos.

Soma personalizada dos valores – Soma os elementos entre dois índices informados.

Média dos valores do vetor – Calcula a média aritmética.

Maior valor dentro do vetor – Mostra o maior número do vetor.

Menor valor dentro do vetor – Mostra o menor número do vetor.

Sair – Finaliza o programa.
